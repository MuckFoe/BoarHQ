# Constitution

This project's constitution is its ruleset, not this file.

- **The rules** — `rules/*.md`, twenty-three rules across nine domains.
- **The bindings** — the Bindings section of `CLAUDE.md`, which says how each
  rule applies here.

A plan's constitution-compliance check walks those. `/sdd-constitution` is not
run in this project; it would write a second set of principles beside the first
(decided 2026-10-09, `rules/_decisions.md` § Structural decisions 7).
