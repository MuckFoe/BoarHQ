# Concepts

Domain vocabulary and the invariants that hold in this system. One accumulating
file — never one per feature (VER2). This is also where the canonical term for
each concept is fixed, which is what makes STY1 checkable.

An entry is: the term (German and English where they differ), what it means
*in this system*, and any invariant that must hold.

Add a concept when a feature introduces or changes one. A feature that
introduced no new concept adds nothing here, and that is a valid outcome.
